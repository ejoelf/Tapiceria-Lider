# CRM Líder

React + Vite + TypeScript + Tailwind. Iniciar e instalar desde la raíz del monorepo, siguiendo el [README principal](../README.md). Puerto local 5174. La API usa cookies HTTP-only y el proxy `/api`.

Las pantallas están en `src/pages`, los controles compartidos en `src/components`, y los campos de recursos en `src/lib/resources.ts`. Los permisos de frontend mejoran la navegación; el backend siempre vuelve a verificarlos.
