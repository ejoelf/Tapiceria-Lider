# Web pública Líder

Next.js App Router + TypeScript. Iniciar e instalar desde la raíz del monorepo, siguiendo el [README principal](../README.md). Puerto local 3000. `API_INTERNAL_URL` solo se usa en el servidor. El formulario pasa por `/api`.

La imagen `public/volante-lider.png` fue generada como imagen ilustrativa del diseño: no corresponde a un cliente ni se presenta como un trabajo real. Los antes/después reales se cargan y publican desde el CRM.
